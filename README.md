A complete, full-stack clinical-scientific analytics web application and pharmacokinetic modeling platform for **Target-Controlled Infusion (TCI)** of **Remifentanil**, implementing a **Grey-Box Hybrid Architecture** combining the classical **Minto (1997) 3-Compartment + Effect-Site Ordinary Differential Equation (ODE)** model with 8 machine learning residual learners and **95% Split-Conformal Uncertainty Prediction Intervals**.

## 🔬 Scientific & Architectural Overview

### 1. The Pharmacokinetic Mechanistic Foundation
Remifentanil distribution and elimination are governed by a three-compartment mammillary differential equation system coupled with a first-order effect-site pharmacodynamic transfer equation:

$$\frac{dA_1}{dt} = R(t) - (k_{10} + k_{12} + k_{13})A_1 + k_{21}A_2 + k_{31}A_3$$
$$\frac{dA_2}{dt} = k_{12}A_1 - k_{21}A_2$$
$$\frac{dA_3}{dt} = k_{13}A_1 - k_{31}A_3$$
$$\frac{dC_e}{dt} = k_{e0}(C_p - C_e)$$

where:
- $A_1, A_2, A_3$ are amounts in central, shallow peripheral, and deep peripheral compartments ($\mu\text{g}$).
- $C_p = A_1 / V_1$ is arterial plasma concentration ($\text{ng/mL}$ / $\mu\text{g/L}$).
- $C_e$ is effect-site concentration ($\text{ng/mL}$).
- $R(t)$ is intravenous infusion rate ($\mu\text{g/min}$).
- Volumes ($V_1, V_2, V_3$) and clearances ($Cl_1, Cl_2, Cl_3$) are dynamically computed as covariate functions of Age and Lean Body Mass ($LBM$, James 1976 equation).

### 2. Multiplicative Grey-Box Log-Residual ML Formulation
Pure black-box neural networks or trees can violate mass conservation or predict non-physical negative concentrations. Conversely, uncorrected compartment ODEs suffer from unexplained inter-individual variability (IIV). 

The grey-box framework bridges this gap by training supervised learners on log-residuals:

$$r = \ln(DV) - \ln(C_{p,\text{minto}})$$

Predictions are reconstructed via damped exponential inversion:

$$\hat{C}_p(t) = C_{p,\text{minto}}(t) \cdot \exp(\lambda \cdot \hat{r}(t))$$

This mathematically guarantees:
- Non-negative concentration predictions $\hat{C}_p(t) > 0$.
- Preservation of physical clearance asymptotic decay during washout phases.
- Zero prediction drift during zero-dose baseline intervals.

### 3. Distribution-Free 95% Split-Conformal Prediction Intervals
To provide patient safety error bounds, point predictions are augmented with split-conformal calibration:

$$s_i = |\ln(y_i) - \ln(\hat{y}_i)| \quad \text{on independent calibration subjects}$$
$$q_{1-\alpha} = \text{Quantile}_{1-\alpha}(s)$$
$$\hat{C}_p^{\text{low}}(t) = \hat{C}_p(t) \cdot \exp(-q_{1-\alpha}), \quad \hat{C}_p^{\text{high}}(t) = \hat{C}_p(t) \cdot \exp(q_{1-\alpha})$$

## 💻 Technology Stack

### Frontend
- **HTML5 & Modern CSS3**: Dark navy theme (`#060b14`), cyan accents (`#06b6d4`), responsive layout.
- **JavaScript (ES6+)**: Modular MVC design, Chart.js for real-time medical charts.
- **Chart.js 4.4**: Line plots with shaded uncertainty bands, scatter overlays, residual funnels.
- **Fetch API**: Centralized communication to the FastAPI backend.

### Backend
- **Python 3.10+**
- **FastAPI**: Asynchronous high-performance REST API with Pydantic validation schemas.
- **Uvicorn**: Lightning-fast ASGI production server.
- **NumPy & Pandas**: Matrix mathematics and clinical dataset manipulation.
- **SciPy**: Pharmacokinetic numerical routines and linear algebra.
- **Scikit-learn**: GroupShuffleSplit cross-validation, preprocessing scalers, ensemble regressors.
- **XGBoost & CatBoost**: Gradient-boosted decision trees.
- **Joblib**: Persistence of trained model weights and calibration metadata.

## ⚡ Running the Application

### Option A: Unified Launcher (Recommended)
Run the root launcher, which starts Uvicorn and automatically launches your default web browser:
```bash
python run.py
```
Open your browser at:
👉 **`http://127.0.0.1:8000`**

- **Interactive Clinical Dashboard**: `http://127.0.0.1:8000`
- **Swagger Interactive API Documentation**: `http://127.0.0.1:8000/docs`
- **OpenAPI JSON Specification**: `http://127.0.0.1:8000/openapi.json`

### Option B: Standalone Frontend Development Server
If you prefer running the frontend on a separate dev server (e.g., port 5173):
```powershell
# Terminal 1: Backend API
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload

# Terminal 2: Static Frontend Server
cd frontend
python -m http.server 5173
```
Visit `http://localhost:5173` — `frontend/js/api.js` automatically routes API calls to `http://127.0.0.1:8000/api`.

## 💡 Troubleshooting

- **CORS Issues in Development**: Ensure backend `ALLOWED_ORIGINS` in `.env` includes your frontend port (e.g. `http://localhost:5173`).
- **Missing Dataset**: The app looks for `data/Kaggle_PK_Remifentanil.csv`. If absent, use the Dataset Explorer to upload your CSV file.
- **Port Conflict**: If port 8000 is occupied, launch on another port:
  ```bash
  python run.py --port 8080
  ```
